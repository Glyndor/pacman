# What each package may install, one line per package: the package name, a TAB, and the path patterns, separated by spaces.
#
# The rule is default deny. A member of a package that no pattern of its line names refuses the whole release, and so does a
# symbolic or hard link that points anywhere else than at a place its package may install or at a `>` place. A pattern is a path
# with no leading slash; `*` is any characters inside one component; a trailing `/` is a folder and everything under it; a leading
# `>` marks a place that links may point at without the package installing it (a file of the other package of the same release).
#
# Never allowed, whatever is written here (pkgpolicy.py FORBIDDEN, and a line that names one makes the file refuse to load): pacman's
# own files (etc/pacman.conf, etc/pacman.d, usr/share/pacman with the keyrings, usr/share/libalpm with the hooks), sudo, the
# users and passwords, the login and the loader, cron, udev rules, etc/systemd and ssh. Units, sysusers and tmpfiles are allowed
# only under the name of the package.
#

# carry (docs/product-contract.md). A product that needs another place asks for it here, in a reviewed change.
